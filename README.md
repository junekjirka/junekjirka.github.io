# Statický SEO web (CZ)
Bez buildu, čisté HTML. Před nasazením spusťte `./deploy.sh <URL>` (doplní canonical, sitemap, robots).
- **GitHub Pages:** repo `UZIVATEL.github.io` (veřejné), nahrát obsah složky, Settings → Pages → Deploy from branch `main` / root.
- **Cloudflare Pages:** Workers & Pages → Create → Pages → Upload assets → nahrát složku (zdarma, adresa *.pages.dev).
Stav dat a zdrojů: 12. 10. 2026. Před zveřejněním doporučuji, aby provozovatel fakta zkontroloval.
